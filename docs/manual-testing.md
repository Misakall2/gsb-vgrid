# 浏览器手测说明

先按 README 启动静态服务，再打开页面：

- `http://127.0.0.1:8000/index.html?rows=0`：空表。
- `http://127.0.0.1:8000/index.html?rows=1`：单行。
- `http://127.0.0.1:8000/index.html?rows=10000`：一万行。

建议手工检查：

- 纵向快速滚动后，行仍与 32px 行高对齐，底部不会出现负偏移。
- 横向滚动时，表头首列和正文首列都固定在左边缘。
- Shift+方向键拉选区，滚动到远处再滚回，高亮仍按原始数据行保留。
- 双击单元格后打开中文输入法，组字期间按方向键、Enter、Tab 不提交。
- 筛选、分组、折叠分组后，编辑器和选区仍绑定原始数据坐标。
- 调整首列宽度后，表头、冻列、正文和编辑器边框对齐。

本机装有 Chrome 或 Chromium 时，可以额外运行：

```sh
node test/manual/browser-regression.js
```

这个脚本需要浏览器，属于可选手测辅助；CI 和 `node scripts/test.mjs` 不依赖它。
